# Float Desktop Widget

Windows floating desktop clock and productivity widget built with Python and PySide6.

Current app release: **8.0.0**.

The app checks `latest.json` for release information. Tasks and preferences are stored locally at `%LOCALAPPDATA%\\FloatWidget\\data.json` and are not part of this repository.

The initial update-enabled package is distributed separately. Future automatic upgrades require a published, checksum-verified update bundle referenced by the release manifest.
